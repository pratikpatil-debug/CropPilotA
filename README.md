# WHY ARE YOU ASKING ME?
### *The Overloaded, Satirical, Extremely Annoying AI Q&A Engine*

An intentionally chaotic, overloaded control panel website designed like 20 disconnected teams built it without communicating. It bombards the user with fake telemetry, dials, 20+ satirical mock advertisements, and intrusive "click-trap" and "typing-trap" interruptions—**while always delivering a genuine, 100% accurate, high-quality answer**.

---

## 🚀 Features

- **5 Distinct Visual Eras Fighting for Attention**:
  - Windows 98 beveled utility menubar with live clock and audio toggles.
  - Cyberpunk Web3 telemetry sub-toolbar with live entropy, click-counters, and defragmenters.
  - Brutalist Hazard sidebar with oscillating gauges, dynamic odometer visitor counter, and real-time askers feed.
  - 1996 Geocities academic table and permanent construction banners.
  - Cluttered 5-column mega footer with over 30 absurd links.
- **Genuine Knowledge Core**:
  - Comprehensive verified local science & technology archive.
  - Real-time Wikipedia REST API integration for dynamic encyclopedic answers.
  - Speech synthesis read-aloud and one-click answer copying.
- **Satirical Annoyances**:
  - **20+ Unique Mock Advertisements**: 100% satire, clearly labeled, safe, with quick-skip countdowns.
  - **Click-Anywhere Interceptor ("Click Trap")**: Clicking anywhere on the page spawns cursor ripples, counts wasted clicks, and triggers surprise mock ads.
  - **Live Keystroke Advertising ("Typing Trap")**: Every character typed updates a live sponsorship banner (vowels, consonants, spacebars), with configurable typing mock ads (Every Word, Every 5 Chars, or Hyper Every Key).
  - **8-Stage Processing Chamber**: Complicated stages including "Checking the checker", "Consulting unnecessary systems", and slipping progress bars.
  - **The "Fair Enough" Departure Screen**: When you click "I'm Never Using This Again".

---

## 🛠️ Tech Stack

- **HTML5**
- **Vanilla CSS3** (No external frameworks, custom responsive grid, animations, and clashing typography)
- **JavaScript (ES6+)** (Web Audio API synthesizer, Wikipedia REST API, Web Speech API)

## 💻 Running Locally

Simply open `index.html` in any modern web browser:
```bash
# Or start a local server
python -m http.server 8080
```
Then visit `http://localhost:8080`.
